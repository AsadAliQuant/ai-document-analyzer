# Phase 4 - Milestone 1 - Remove Offline Support

## Execution rules

- This milestone owns offline/Ollama removal and the stable Gemini-only application flow. It does **not** move Gemini key ownership; that is Milestone 2.
- Keep the Gemini credential/transport boundary isolated so Milestone 2 can replace direct Google calls with the admin-managed backend gateway without rewriting document, OCR, summary, or Q&A logic.
- Keep local Qdrant for RAG. References to an offline license/network state are not offline AI support and must not be removed accidentally.
- The canonical future release is the one-folder build consumed by NSIS. Milestone 1 may remove obsolete AI dependencies from its active build inputs, but installer and standard-user changes belong to Milestone 3.
- A completed task is reopened only for a confirmed regression; later acceptance checks are separate tasks, not repetitions of implementation work.
