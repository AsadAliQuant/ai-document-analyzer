# Phase 4 - Milestone 3 - Installer and Standard-User Execution

## Execution rules

- Start only after Milestone 2 acceptance so the installer is built once from the final desktop dependencies, configuration format, and backend transport.
- Use the existing one-folder PyInstaller path plus NSIS as the canonical release pipeline. Do not create a second installer technology in parallel.
- The installed application and per-user installer must run without elevation. Install under the current user (for example `%LOCALAPPDATA%\Programs\AI Document Analyzer`), register uninstall data under `HKCU`, and create current-user shortcuts.
- Runtime code must treat installed program files as read-only. Persistent writes go to documented user-specific directories; ephemeral extraction/work files go to the user temp directory.
- Preserve user data during upgrades. Uninstall behavior for user data must be explicit and tested; never silently delete it.
- A completed task is reopened only for a confirmed regression; final artifact verification is not a repeat of implementation.
